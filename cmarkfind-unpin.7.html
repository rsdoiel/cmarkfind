NAME

cmarkfind-unpin — remove a pin

SYNOPSIS

cmarkfind unpin ADDRESS…

DESCRIPTION

Remove pins. The pages stay in the corpus.

OPTIONS

-json
Write {“unpinned”: N}.

EXIT STATUS

1 when none of the addresses was pinned. See cmarkfind-exit-status(7).

SEE ALSO

cmarkfind(1), cmarkfind-pin(7)
