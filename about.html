About this software

cmarkfind 0.0.0

Authors

  • R. S. Doiel

CMarkFind is a Go module inspired by PageFind. It seeks to provide a personal search engine for the Markdown Web and be embedded in Markdown Web browsers like cmarkbrowser of potentially BonBon.
