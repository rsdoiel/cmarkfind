NAME

cmarkfind-query — the search syntax

DESCRIPTION

A query is SQLite’s FTS5 syntax, searched over each page’s title, description and body.

oberon compiler          both words (AND is implied)
oberon OR modula         either word
oberon NOT pascal        the first and not the second
"shallow water"          the words next to each other, in order
compil*                  words that start with compil

Case does not matter. A title match counts for more than a description match, and a description match for more than one in the body (bm25 with weights 4, 2 and 1). Hits that rank the same are put in the order bookmarked, read, own, toc pages, then by address.

Text that is not valid FTS5 syntax (an unbalanced quote, a stray operator) is searched as plain words, so a typo returns hits and not an error. Pages marked gone are not searched.

EXAMPLES

cmarkfind search '"shallow water" NOT tide'
cmarkfind search -- -dash
