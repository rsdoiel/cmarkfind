## cmarkfind 0.0.0



### Authors

- R. S. Doiel, <https://orcid.org/0000-0003-0900-6903>






CMarkFind is a Go module inspired by PageFind. Instead of working with HTML, 
CMarkFind works withe CommonMark documents and their front matter.
It can create the indexes suitable for a static website search and
also allows those indexes to be reused on the command line.
